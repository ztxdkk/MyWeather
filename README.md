# MyWeather - Android天气应用

## 项目简介
一款基于 Kotlin 开发的小型 Android 天气查询应用，采用 MVVM 架构模式，实现城市天气信息查询与展示，代码结构清晰，便于维护扩展。

## 技术栈
- 开发语言：Kotlin
- 架构模式：MVVM
- 网络请求：Retrofit + OkHttp
- 异步处理：Kotlin Coroutines
- UI 布局：ConstraintLayout

## 核心功能
- 输入城市名称，查询实时天气信息
- 展示天气状况、温度等核心数据
- 网络请求异常处理与容错机制

## 项目亮点
- 采用 MVVM 架构分离 UI 与业务逻辑，符合安卓开发规范
- 使用 Retrofit 进行网络请求，配合协程实现异步操作
- 完整使用 Git 进行版本控制，代码同步至 GitHub 公开仓库
