# MyWeather - Android 天气应用

## 项目简介
一款基于 Kotlin 开发的小型 Android 天气查询应用，采用 MVVM 架构模式，实现城市天气信息查询与展示。本次版本对 UI 进行了全面美化升级，代码结构清晰，便于维护扩展，同时支持与旧版本共存安装，保留学习纪念意义。

## 技术栈
- 开发语言：Kotlin
- 架构模式：MVVM
- 网络请求：Retrofit + OkHttp
- 异步处理：Kotlin Coroutines
- UI 布局：ConstraintLayout
- 视图绑定：View Binding

## 核心功能
- 输入城市名称，查询实时天气信息
- 展示天气状况、温度、湿度等核心数据
- 网络请求异常处理与容错机制
- 全新美化 UI，包含圆角输入框、主题色按钮与卡片式布局
- 自定义天气应用图标，桌面辨识度高
- 支持与旧版本共存安装，不覆盖原有版本

## 项目亮点
- 采用 MVVM 架构分离 UI 与业务逻辑，符合安卓开发规范
- 使用 Retrofit 进行网络请求，配合协程实现异步操作
- 本次版本新增完整 UI 美化，界面更现代化、视觉效果更佳
- 自定义应用图标，打造专属天气应用标识
- 修改包名，实现新旧版本双共存，便于对比学习与纪念
- 完整使用 Git 进行版本控制，代码同步至 GitHub 公开仓库

## 运行说明
- 环境：Android Studio Hedgehog | 2023.1.1 及以上
- 最低支持：Android 7.0 (API 24)
- 权限：需开启网络权限以获取天气数据
- 安装方式：支持无线调试直接安装到手机，新旧版本可同时存在
